
🐍 FLOP Snake Game

A classic Snake game customized in the style of the FLOP project. Built with pure HTML5 Canvas and JavaScript to practice basic DOM manipulation, event handling, and game loops.

🚀 Demo

Play the game directly in your browser:
👉 Play FLOP Snake Game

🪐 About FLOP Style

This version of the game is inspired by FLOP Finance. The visual theme has been completely redesigned:
• The background matches the official FLOP deep blue color palette.
• A customized FLOP text watermark is integrated directly into the game canvas grid.
• The snake and interface elements use the project's signature bright blue accent colors.

🛠️ Tech Stack

• HTML5 – canvas grid rendering and custom SVG branding
• CSS3 – dark theme styling and responsive layout
• JavaScript – game logic, custom boundaries, and movement

🎮 How to Play

• Use Arrow Keys (← ↑ → ↓) to control the snake.
• Eat food blocks to grow and gain points (+10 per food).
• Avoid hitting the walls or your own tail.

⚙️ Features

• Custom 1.5x larger rectangular game field (600x400)
• Fixed optimal game loop speed for smooth navigation
• Dynamic score counter
• Clean, lightweight code with zero external dependencies
