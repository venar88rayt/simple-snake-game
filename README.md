# simple-snake-game
A simple Snake game built with HTML5 Canvas and JavaScript


🐍 Simple Snake Game

A classic Snake game built with pure HTML5 Canvas and JavaScript. Developed as a project to practice basic DOM manipulation, event handling, and game loops.

🚀 Demo

Play the game directly in your browser:
👉 Play Snake Game

🛠️ Tech Stack

• HTML5 – canvas grid rendering
• CSS3 – dark theme styling
• JavaScript – game logic and movement

🎮 How to Play

• Use Arrow Keys (← ↑ → ↓) to control the snake.
• Eat red squares to grow and gain points (+10 per food).
• Avoid hitting walls or your own tail.

⚙️ Features

• Responsive keyboard controls
• Dynamic score counter
• Clean, lightweight code with no external dependencies
